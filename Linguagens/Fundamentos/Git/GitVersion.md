# git --version

Uma das formas de ver se o **[Git](./Index.md)** foi instalado corretamente é através do comando `git --version` no terminal (cmd) do windows. Esse comando irá retornar a versão presente na máquina.

```cli
git --version REM git version 2.55.0.windows.4
```
